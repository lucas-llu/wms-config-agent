# P4 用量与额度：实施中

2026-10-07，基线 dev/2119b9b，分支 feature/usage-quota。
本阶段不启动生产、不迁移旧账、不调用付费供应商；新模式需明确 WMS_P4_ENABLED=1，且只能接 P3 持久任务入口。

## 第一批实现

- 月 token 额度：默认 1000000，运行预算预留 100000，均可配置，管理员可调整各用户上限。
  提交/outbox/预留同事务；同键重试不重复占用；账号级短事务锁防止并发绕过。
- 每次供应商调用独立 admission/attempt；本地检查点缓存命中不创建第二笔调用。
  供应商返回、平台估算、未知待对账分开。输入/输出/缓存/推理子集不能重复加到 total。
  [DeepSeek usage 官方合同](https://api-docs.deepseek.com/api/create-chat-completion/)仅用于字段含义，
  不把 DeepSeek 原生价格当成 OpenCode Go 的代理收费。
- 未确认价格默认未定价，不显示确定费用或用 0 冒充未知。价格为管理员配置的 version/currency/
  input/cached/output 每百万 token 十进制字符串，明确 confirmed。每个运行冻结价格快照，费用标注估算。
- 取消/失败的已知消耗仍记账；未知调用保留原调用预算待对账，未使用预留释放。
  返回结果即使随后身份被撤销也先以元数据写入计量，不发布迟到回答。
- UTC 保存事件，Asia/Shanghai 分日/月。跨月调用转移未使用运行预算到调用发生月份，
  老月份已知消耗与未知保留不被转走。供应商超出预算仍如实记用量，阻止进一步超额，不抹掉实际消耗。
- 对话回收/永久删除不删会计记录。用量表无聊天正文、token、密码或模型返回文本，只含 opaque 绑定与数字。
- 用户仅看本人汇总/明细，可按模型、策略、对话过滤；管理员看账号/聚合，不取得私人聊天。
  修改额度、账号启停、成员关系、待对账确认均需平台角色与审计；普通 workspace_admin 不是平台管理员。

## 接口与开关

个人：GET /v1/me/usage、/v1/me/usage/attempts。
管理：/v1/admin/accounts、/accounts/{id}/quota、/accounts/{id}/status、/memberships、
/usage、/usage/unresolved、/usage/{attempt}/reconcile。
授权与审计：GET /v1/admin/authorization、GET /v1/admin/audit，
PUT /v1/admin/workspaces/{workspace_id}/scope。成员修改携带 expected_revision；
范围/成员首次创建版本为 0，后续修改必须提交读到的版本，过期返回 409，不覆盖新授权。
对账必须携带 expected_revision 与原因；不能重复确认同一笔未知消耗。

WMS_MONTHLY_TOKENS、WMS_RUN_TOKEN_RESERVE、WMS_MODEL_PRICE_JSON 为可选配置。
生产 API/执行器必须匹配模型/计量配置。005/006 迁移在 004 后顺序运行，不能作为公开请求启动 DDL。
测试迁移器只在隔离 WMS_P3_LIVE=1 环境使用，正式迁移与旧数据回退仍属于 P5。

## 用户交互与管理边界

- 用户中心“我的用量”仅查本人；平台管理员额外看到“额度与账号管理”。
  工作区管理员不是平台管理员，即便在共享工作区也不能查看他人的私人问答。
- “知识范围与工作区”创建/编辑明确的 collections/modules/sites/environments，禁止 `*`、
  空列表或 legacy。此界面只管理范围授权，不负责上传、重建或删除知识索引。
  缩小范围后，后续检索/执行重新校验；已有证据读取也必须满足最新范围。
  包含已撤销范围证据的旧对话停止提供正文、历史版本和导出内容，不删存储记录，
  用户可在当前授权范围新建对话。首版读取检查历史 state/citations，长对话的性能仍需 P5 压测。
- “成员与角色”选择账号、工作区、角色及启用状态。撤销阻止后续访问/执行，不删除私人数据。
  账号停用撤销已有 token；重新启用也不恢复旧 token，用户须重新登录。
- 管理员修改额度/账号、范围/成员及对账，都要明确原因和确认，并产生管理审计。
  审计展示操作元数据，不提供私人聊天正文；加载失败不伪装为成功，版本冲突须刷新重确认。
- 待对账只列已结束的未知/平台估算调用，在途调用不能手工结算。
  确认输入、输出、缓存、推理四个非负整数；缓存 ≤ 输入、推理 ≤ 输出，total = 输入 + 输出。
  核对供应商记录后提交原因及版本，成功重新结算额度；二次提交返回 409，无第二次扣费/审计。
  不自动读取供应商账单；未确认代理价格仍保持未定价，不能据此声称真实成本准确。
- 列表首版上限：账号/范围/账本/审计 100、成员 1000。面向更大规模的分页/导入是后续工作，
  P5 小团队测试必须先核对人数及数据量，不静默承诺无限管理规模。

## 真实浏览器验收方式

隔离 Linux CI 使用 Chromium、真实 Keycloak 验证邮件、PostgreSQL 非 owner/RLS、Redis/RQ
与内部执行器；模型与知识是明确的无费用合成 fixture，不替代真实供应商质量/成本验收。
WMS_P4_BROWSER 仅启用该测试 fixture 的公开/执行器计量，不能用于生产。
新增浏览器流程验证范围创建、成员授权、实际问答与账本匹配、管理员不得读取他人聊天、
未知调用对账/重复提交、额度调整、成员撤销、账号启停及旧 token 失效；同时保留原 P2/P3 五项。
浏览器 JUnit 与合成截图保存为 Actions `browser-acceptance`，保留 7 天；不保存 token/密码/真实资料。
