# 单次旁路核验退役（2026-10-13）

根据用户实际试用结果，移除可选旁路核验。默认流程继续使用完整证据片段、结构/引用验证和最多一次定向补查。

- 工作台不再提供核验开关，也不发送策略选择字段。新建、继续和异步提交接口仅接受 `standard`；显式传入旧 `review` 返回 422。
- 回答管线不再运行旁路判断/修订，独立执行槽和模型子额度已移除。全局在途、RPM/TPM、用量计量与用户公平调度仍有效。
- 旧旁路任务升级后不能再次调用模型；无在途调用的任务结束为 failed，有未知调用的任务保持 uncertain，等待对账。
- 历史回答、用量和已安装 SQL 迁移不改写。历史核验过滤及标记只用于查看旧记录；模型限流配置兼容旧 `review_inflight` 字段。
- 配置草稿的人工审批、reviewer 角色及默认回答的证据引用功能保留。P5 后续验收改为默认回答、补查、多轮对话的负载。

仅通过合并并部署新版本才能撤去已安装页面上的旧开关；本地私有历史数据不会随源码提交。

## 2026-10-18 复查

新接口、工作台和执行器只允许默认策略。P0 接口设计同步为 standard-only。
本机新负载与显式启用的语料回放也只生成默认策略；旧旁路计划可核对已有结果，不能重新提交缺失任务。
旧实验说明归档保留，不能作为当前启用说明或继续执行已移除的评估命令。
历史用量过滤、已安装迁移、旧任务拒绝/对账测试，以及未激活的回退包中的旧标记仍用于兼容与审计，不应机械删除。
